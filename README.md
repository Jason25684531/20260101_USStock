# USStock Project

## Overview
This project provides a stock trading platform with the following components:
- **Database**: MySQL for storing market data and trade logs.
- **Strategies**: Python-based trading strategies using VectorBT.
- **Web**: Flask-based dashboard and LineBot integration.

## Setup
1. Clone the repository.
2. Set up `.env` and `.secrets/`.
3. Run `docker-compose up` to start the services.
