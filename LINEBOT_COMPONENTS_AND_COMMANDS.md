## 2️⃣ 命令完整映射表

### 所有可用命令

| 命令 | 別名 | 調用函式 | 輸出型態 | 需要 DB | 說明 |
|------|------|---------|---------|--------|------|
| `/help` | `幫助` | 內建文字回覆 | 文字 | ❌ | 列出所有可用命令和使用說明 |
| `Top5` | `top 5`, `推薦`, `/top5`, `/scan` | `_cmd_top5()` | Flex Card | ✅ | 今日 Top 5 推薦 (含 ML 圖表) |
| `Top5基礎` | `top5-basic`, `/top5basic`, `/basic`, `基礎` | `_cmd_top5_basic()` | 文字/卡片 | ✅ | Top 5 純規則推薦 (無 ML) |
| `/stock SYMBOL` | `個股 SYMBOL`, `查股 SYMBOL` | `_cmd_stock()` | 文字 | ✅ | 查詢單個股票詳細分析 |
| `/market` | `市場`, `宏觀`, `/macro` | `_cmd_market()` | 文字 | ✅ | 查看宏觀環境 (VIX, GDP 等) |
| `/sector` | `產業`, `板塊`, `/sectors` | `_cmd_sector()` | 文字 | ✅ | 查看產業動能排行 (11 個產業) |
| `/history MMDD` | `歷史 MMDD` | `_cmd_history()` | 文字 | ✅ | 查看指定日期的推薦紀錄 |
| `/status` | `狀態` | `_cmd_status()` | 文字 | ✅ | 系統狀態 (策略績效、連接狀態) |
| `ML SYMBOL` | `/ml SYMBOL` | `_cmd_ml()` | 文字 | ✅ | 查看 ML 模型對該股票的信心度 |
| `/strategies` | `策略` | 內建文字回覆 | 文字 | ❌ | 列出策略組合與版本資訊 |

## 5️⃣ 常見問題速查

| 症狀 | 根本原因 | 快速修復 |
|------|--------|--------|
| ngrok ERR_NGROK_3004 | 多個 Flask 進程 | `taskkill /F /IM python.exe` 後重啟 |
| LINE 無回應 | Webhook URL 未配置 | 在 LINE Developers Console 更新為 ngrok URL |
| 403 Forbidden | 簽名驗証失敗 | 檢查 .env 中的 Channel Secret 是否正確 |
| 命令無法識別 | 命令格式錯誤 | 檢查空格、英文大小寫、特殊字符 |
| 數據為空 | MySQL 連接失敗 | 啟動 MySQL 服務或檢查端口 3308 |
| Flex Message 格式亂 | JSON 結構錯誤 | 檢查 handler.py 中的卡片 JSON 定義 |
